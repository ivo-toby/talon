## Thread Memory

Use `memory_access` to store and retrieve facts, summaries, and notes for the
current thread. Memory items persist across conversations and help you maintain
context over time.

- Use `action: "store"` to save important facts, decisions, or user preferences.
- Use `action: "retrieve"` to recall previously stored information.
- Use `action: "list"` to see all memory items for the current thread.
