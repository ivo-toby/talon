# Mandatory first step for the WhatsApp Business task

The planner must place this first step at the start of the WhatsApp Business
worker brief, before any media mapper implementation:

1. Verify the current primary media contract for the connector's configured
   apiVersion. Read and cite the media-ID lookup request, authentication headers,
   response envelope and fields consumed by the mapper, and the download-URL
   request/authentication/byte response. Record the version and actual source
   file/line references in research. Do not derive the mapper from the v13
   screenshot: it is historical evidence, not a verified current response.

If the current contract cannot be read, record it as NOT READ and report the
missing prerequisite to the controller; do not invent its shape. No operator
credentials or live API call are required merely to read a public contract.

Lasting starting references are E3 in the
[contract inventory](../../../shared-context/contract-inventory.md) and the
primary URLs/version pins in [source-manifest.json](source-manifest.json).

This is a task prerequisite, not an approved task graph or a dispatched worker
brief. The eventual brief must include this text and link this artifact.
